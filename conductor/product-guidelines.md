# Product Guidelines

Communication standards and brand voice for the Storefront Purchase Flow.

## Brand Voice and Tone

### Principles
- **Clear and Transparent**: Always communicate pricing and value clearly
- **User-Centric**: Focus on user needs and journey clarity
- **Trustworthy**: Build trust through consistency and transparency
- **Helpful**: Guide users through the process without overwhelming

## Terminology and Glossary

### Key Terms
- **Anonymous Cart**: Cart functionality for users who haven't authenticated
- **Authenticated Cart**: Cart functionality for logged-in users
- **Cart Service**: Backend service managing cart operations
- **Package Picker**: Component for selecting Premium or Mailbox packages
- **Split Page**: Page that splits purchase flow for different user types
- **MiniCart**: Compact cart component for navigation/header
- **Validations**: Cart validation rules and error handling

### Domain-Specific Terms
- **One-year free domain**: Promotional offer that must be explicitly communicated
- **Multi-year registration**: Domain registration for multiple years
- **Privacy add-ons**: Additional services for domain privacy
- **Brand protection bundle**: Package including domain and brand protection services

## Error Message Conventions

### Cart Validation Errors
- Be specific about what failed validation
- Provide actionable guidance on how to fix
- Use clear, non-technical language
- Show errors in context (near the relevant field/action)

### Anonymous Flow Errors
- Clearly indicate when authentication is required
- Explain benefits of creating an account
- Provide path forward without blocking

## User-Facing Copy Standards

### Pricing Communication
- Always show real numbers
- Break down costs clearly (base price, add-ons, discounts)
- Highlight value propositions explicitly
- Make promotional offers (like one-year free) prominent

### Progress Indicators
- Show clear progress through the flow
- Indicate current step and remaining steps
- Use consistent visual language

### Success Messages
- Celebrate completion with clear, positive messaging
- Confirm what was purchased
- Provide next steps clearly
- Avoid overwhelming with too much information

## Documentation Style

### Technical Documentation
- Use clear headings and structure
- Include code examples where relevant
- Document decisions and rationale
- Keep context-driven development artifacts updated

### User Documentation
- Focus on user goals, not technical implementation
- Use screenshots and visual aids
- Provide step-by-step guidance
- Include troubleshooting sections

## Communication Patterns

### Anonymous User Flow
- Welcome anonymous users
- Explain benefits of account creation without pressure
- Provide clear path to complete purchase
- Maintain context throughout the flow

### Cart Interactions
- Show cart contents clearly
- Provide easy modification options
- Display pricing breakdown
- Enable quick checkout

### Error Handling
- Show errors immediately
- Provide clear resolution paths
- Don't lose user context
- Allow recovery without starting over
